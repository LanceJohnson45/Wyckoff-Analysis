# Martin Luk 详细实操教程 V3.0

## V3.1 视频课程版

[打开视频教程HTML](Martin_Luk_详细实操教程_V3.0.html)。原15课图文完整保留，按附录引用裁成51段独立教学视频，合计165分23秒，约1.83GB；没有嵌入完整录屏。各课展开“视频讲解”即可播放，切换中文、双语、英文或关闭字幕。

51段视频现采用1080p原始音视频流直接裁剪，不缩放或重新压缩。视频保存在本目录`clips/`，字幕文件在`subtitles/`。移动教程时保留相对目录，不要只复制HTML。网页字幕数据及六张截图已内嵌，MP4为外置文件。[使用说明](视频课程使用说明.md)解释结构、字幕口径与裁剪方式。

**Git仓库仅保存教程、代码、截图、字幕和裁剪清单；51个MP4仅保留本地，不通过Git或LFS上传。** 克隆仓库后，文字与图片可直接阅读；要播放视频，需自行将对应MP4放入`clips/`，文件名见`clips_manifest.json`。当前电脑上的视频与完整课程ZIP均保留，未删除。

中文字幕基于本地ASR和Qwen机器翻译，共1589个原转写段、1887个片内字幕条；术语统一并对47处重要误识/机翻做有记录的修订，仍未逐句人工听校。中文与双语SRT、VTT均可独立使用。`视频课程核验记录.json`记录51段真实音视频的片长、零起点和首尾解码检查。

当前应用内预览通过本机HTTP打开；内置浏览器不允许`file://`导航，因此未在内置浏览器实测双击文件路径打开。视频和字幕均无云端依赖。Word与Markdown仍为图文版，视频交互位于HTML。
