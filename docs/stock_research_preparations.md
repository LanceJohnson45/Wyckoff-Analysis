# 研究输入准备回执

HTTP新建研究及CLI `stock-research run`在run建立前，先提交独立准备尝试。CLI指定快照和默认生成快照两条路径均使用此账本；直接snapshot/sync命令仍保留自身回执，不自动视为一次研究。非法交易日、未认证请求和接单容量冲突不计作已开始的输入准备。

准备失败保留历史报告和观察名单，不制造空研究报告，也不把量化候选当初选。共同输入冻结后由量化job/attempt及模型stage账本负责；输入已冻结与量化/模型完成分别表达。

## 状态与重试

| 状态 | 含义 |
|---|---|
| unconfirmed | 本次结果尚未确认；可能仍在处理，或进程已中断，不推断成功或失败 |
| ready | 真实run已存在、同workspace/目标日、质量通过，且已提交关联；不代表量化或模型完成 |
| failed | 参数、快照质量或共同输入冻结失败，固定错误码与已知质量保留 |
| cancelled | 准备过程被取消并完成回执提交 |

当前阶段为parameters、snapshot、freeze；analysis保留用于读取旧版准备历史，新run在冻结后执行量化。as_of是目标日要求的前一正式交易日，不把未生成快照的日期当已获得行情。quality在尚未完成检查时为null，不补零；已有真实质量报告则保存覆盖、分母、问题和限制。source_hash记录该进程加载的研究版本。

API同幂等请求重试仍未冻结时新增尝试，原失败回执保留；已找到冻结run时复用原run，不重做输入或覆盖成功初选。进程在冻结和回执确认之间硬退出时，旧尝试仍可能unconfirmed；重放可恢复run，不把未知回执伪造为失败。记录不保存原幂等键、文件路径、模型身份或异常原文。

数据库首次提交前不可用时无法创建回执；中途不可用也不能保证终态已写入，先前提交的状态继续如实保留。硬退出回归实际终止独立子进程，重连后仍能读到unconfirmed。

## 查询与Agent

`GET /v1/preparations`支持target_session可选过滤、page>=1和page_size=1～100。确定性排序为create_time倒序及uuid倒序，过滤/分页均在SQL执行。独立只读身份可查询，未认证401；不提供修改、删除或覆盖准备记录的端点。

既有/chat策略研究在运行操作下方显示「输入准备」，按操作区域所选目标日查询，独立于下方所看历史报告。可刷新、翻页、查看质量限制；ready可转到对应研究。创建期间有界轮询，动作返回成功或失败后刷新回执。历史运行没有准备记录时不补造。浏览器控件仍待现有账号正常登录后验收。

显式 `stock-research init-schema`补建受维护的preparation_attempts，schema现有26表；API启动只检查，不自动迁移。payload摘要、状态/日期/请求及run索引共同校验，损坏记录明确失败，不返回空列表代替。终态不可覆盖。

真实隔离workspace用临时100%覆盖要求验证原始501/518对齐快照被拒绝，默认CLI、指定缺失快照CLI和两次API共4条失败均可独立读回，run总数仍0；stocks工作区覆盖要求和参数未改，原报告ID/修订/摘要不变。此为工程失败路径验证，不是收益或策略门槛调整。

研究准备尚不自动协调行情同步；按策略量化异常已进入run独立回执与局部恢复；Personal重试/通知及自然交易日唯一调度继续开发。外部三项只读MCP尚未增加准备回执工具，Agent页面查询与模型工具能力分别验收。独立wiki、远端CI和正式部署未验收。

本批最终验证：全量Python5981、准备/流水线/参数17，Web386与API221通过（两项默认外部Upstash跳过）；TS strict、锁定安装、Web/Pages构建及相关质量/smoke门禁通过，生产42份JS不含两种研究身份。以上不替代未执行的浏览器控件、远端CI或正式部署验收。

API/CLI run量化已使用可取消/限时回收的独立worker，完整校验后才发布缓存；同步analyze保持前台执行。单策略量化失败在run内记录，另一策略继续；准备ready不代表量化完成，详见[量化执行边界](stock_research_quant_execution.md)。
