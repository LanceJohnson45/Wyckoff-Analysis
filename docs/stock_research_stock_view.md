## 已确认锚点叠加

Martin原产物中的突破、摆动高低点提供完整锚点目录，默认选择最近确认的一项；可切换原锚点或关闭显示。锚点原日期和确认日期分别展示，摆动确认间隔沿本报告冻结参数验证。图上均价和确认标记从确认日开始，未显示的确认前区间不代表当时已知该锚点。

单条曲线使用完整冻结日线，从原锚点日起累计(H+L+C)/3乘成交量，再除累计成交量；只截取请求显示窗口，不从该窗口重新累计。截止日重建值须与原daily_estimate在数值容差内相符，否则503。零累计成交量保持null，无有效计算、无已确认锚点与无有效成交量各有说明。曲线是显示重建，不重新识别结构、改变选股或改写旧产物；日线估算、硬过滤关闭，不能证明盘中触发、成交或BUY。

K线显式evidenceLines接收后端点，不在浏览器计算AVWAP。切股/切锚点/关闭时移除旧线和确认标记，尺寸变化或卸载不操作已销毁图表。实际画布和控件交互仍须正常账号登录后验收。

## 固定修订查询

```text
GET /v1/stocks/{symbol}/observations?run_id={RUN_ID}&report_id={REPORT_ID}&limit=320
GET /v1/reports/{REPORT_ID}/anchors/{symbol}?limit=320&index=0
```

股票查询历史上限320根；指定report_id后，初选与互评只取该报告当时视图。报告须属于run/workspace，否则404。锚点查询固定report_id，limit=1～320，index为原产物索引；省略index时按确认日、原日期、索引选择最近项。返回全部目录和一条曲线，未知索引422，未来/损坏确认或末值不匹配503。不启动行情、量化、模型或写入。

外部最小只读客户端ResearchReader.anchor_chart与专用CLI支持相同查询：

```bash
.venv/bin/python -m stock_research.query_cli anchor-chart --symbol GILD --report-id "$REPORT_ID" --index 0 --limit 60
```

专用查询身份可读该固定研究数据，不获得人工维护或私有问答。Personal原三工具、独立研究八工具及绑定问答工具保持原契约，未把所有锚点曲线加入工具响应以免放大证据预算。原martin/{symbol}/anchors/{index}/daily_estimate等标量引用保持；显示曲线不冒充已保存的原因子字段。

「带此股票证据继续讨论」进入[固定报告研究问答](stock_research_chat.md)，后台模型用范围绑定的只读工具读取原事实。不会把后来意见写回旧报告。更多完整成员查询见[整池浏览](stock_research_universe.md)。
