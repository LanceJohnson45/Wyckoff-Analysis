# 盘前有界行情准备

盘前有限API可由operator设置`STOCK_RESEARCH_PREMARKET_REFRESH=true`，在参数/输入版本解析后、快照和run冻结前执行已有只读PG同步。默认false，普通API/CLI run继续原路径。`STOCK_RESEARCH_MARKET_REFRESH_TIMEOUT_SECONDS`默认90秒、允许1～110秒；还受原事件余额及120秒准备总预算约束，外部客户端130秒受理上限保持。输入只接受原schedule，不能选择连接、路径、供应商或期限。

行情身份仍为现有离散`PG_*`，不接受非空PG_DSN。API把本次源连接通过匿名控制管道授予独立worker，不传入argv、文件或回执；worker清空继承环境，使用0700临时HOME，不读取.env，不取得研究库、操作员、模型或Personal身份。只读、可重复读云端事务及原有协作锁、水位、修订与隔离规则保持；同步只能复制云端已有数据，不在线补拉股票或写回云端。

仅当operator已有明确的BENCHMARK_PATH时，worker才调用现有三基准供应商补充，固定原as_of及窗口。完整文件以内容摘要不可变发布；父端等候真实退出，再校验目录/大小/内容/日期/窗口。新路径只供本次准备，不改.env或旧run。随后正式snapshot仍执行SPY逐值对拍、日期覆盖和历史完整性门槛；补充取得不代表质量通过。未显式启用补充时，继续要求云端三个独立benchmark键完整。

## 回执与取消

PREPARATION_ATTEMPTS的payload新增可空`market_refresh`；旧记录缺该字段时读为null，不补造更新历史。回执包括id、as_of、源码版本、开始/终态时间、status、已确认sync计数/水位、benchmark_hash和固定error_code，不含连接、密码或路径。先保存unconfirmed，已完成同步立即持久化，再进行基准补充；后续失败仍保留该步已确认计数，未知步骤为null。只有源事务确认及本机传输成功后才推进水位，后续失败/取消不回退已提交成功，不把未知步骤推断为成功。

取消、超时和异常必须确认本次进程组已终止，才保存失败/取消终态；父端被SIGKILL后，独立控制线程因管道关闭退出，不能留下继续写文件的孤儿。中断可能保留已提交增量，原水位语义允许重放；不会生成伪完成run。这里的父端指直接拥有worker的API/refresh-market进程；外层workflow若HTTP受理未知，仍按原admission_unconfirmed协议处理，不冒称取消已经确认。ready要求更新已确认完成并通过正式快照质量检查。Agent现有「输入准备」显示更新状态、已确认同步、拒收/隔离和错误，仍区分更新、快照质量和研究结果，不新增页面。正常账号浏览器操作另验。

## 显式CLI

```bash
.venv/bin/stock-research refresh-market --as-of 2026-11-20
```

这是受信operator入口，显式执行同一有界worker，不要求盘前开关。仍只同步及已启用基准补充，不调用模型或写研究库；`quality_checked=false`。退出0表示更新步骤完成且无隔离，2表示失败或有拒收/隔离待核对，1表示命令配置错误。后续需按原日期显式生成快照或运行研究；不会自动把CLI结果安装到.env。
