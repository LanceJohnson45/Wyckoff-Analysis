# 历史评估的工程边界

对应 `plan.md` §14.3。实现分为历史量化池回放、冻结正式初选的后续观测、人工审查和参数实验。量化池不改称模型入选，描述性收盘价观测不改称交易回测；工程通过不代表策略有效。

第一批 CLI 使用本地已同步行情，固定截止日、源码、参数和输入全文。只调用 `compute_martin` 和生产 Wyckoff 适配路径，不复制信号公式。抽样仅使用截面之前 SPY 的20日收益；候选日必须拥有三基准320日完整窗口，并为最长标签预留20个正式交易日。选择20个等距秩后按日期排序，12/4/4分组；跨下一组起点的20日标签标记净化。缺股票行情、行业或策略暖机仍列出原排除和分母，不以 `dropna` 隐藏。

当前清单不能静默改成历史清单。仅显式 `--allow-current-universe` 允许构造带限制的当前成分/当前分类回溯视图：保留原版本全文及摘要，派生视图以独立版本和限制注明调整有效期。不能称严格时点研究；旧运行和源文件不修改。没有足量完整截面时命令失败，不用重复日期凑20个。

表现窗口为1/3/5/10/20个XNYS交易日，以截面收盘为参考价。完整内部股票及SPY行情缺一记 missing_data；未结束记 pending，即使输入恰有未来数据也不提前计算。MFE/MAE只取参考收盘之后窗口的高/低。收益单位为百分数；净收益调用现有美股往返成本，净超额为净收益减SPY毛收益，成本为工程估算而非实际成交费用。封存组默认不输出表现；本轮不提供释放开关。净化样本保留审计但不参与拟合或比较。

CLI产生可独立校验的不可变本地产物，不创建模型调用、订单、通知或参数发布。API已采用有界隔离作业和分页结果表；只读HTTP不执行整批回放或重新读完整行情。实验界面、正式模型入选观测、每策略10入选/10排除人工审查、单参数网格和受控组合、AKQuant整批性能比较仍需后续实现与验收，不据此勾选阶段六完成。研究结果和参数比较证据发布到GitHub Issue，不提交到本目录。

## 评估API边界（源码已接，运行包采用另记）

`POST /v1/evaluations` 为operator显式动作，要求Idempotency-Key，只接收profile、cutoff和明确的当前池回溯选择；不接受本地路径、SQL、连接、模型或任意参数代码。202返回作业身份与状态。GET列表、详情、样本均SQL分页，单页最多100；取消为独立POST。只读身份不能发起/取消，盘前身份不获得评估权限。正式初选观测采用单独kind及固定报告身份，不复用量化池标签。

作业、完成结果和逐股样本分表；结果元数据不保存整份行情或全部样本JSON。每个样本引用固定截面/策略/参数和原池，缺数与封存状态可见。唯一请求键/载荷摘要防止未知响应重放创建第二个作业；原冻结清单在重放时不重新消费当前参数/成员。完成结果只追加，不改旧报告。所有表显式init-schema，不在服务启动时迁移。

整批计算放独立worker，网络/数据库/模型身份不传给worker。父端只传已冻结的小配置与受控输入/输出定位，控制管道EOF、取消和超时必须等到所属进程组退出。首轮行情成功物化后重试只读该输入，不能悄悄采用后来修订；冻结前中断、冻结后中断与结果发布后回执丢失分别验证。源码变化明确失败，旧结果仍可读。总预算和协议输出/输入大小有界，不能把CLI的协作式超时宣称为worker硬超时。

评估任务与研究/问答共享接单容量，另保证同一workspace最多一个批量API评估实际执行；不得另开无界队列或在HTTP线程里读取大行情。恢复、关闭和重试已纳入服务生命周期，部署零活动检查需包含评估任务。后续组件放现有Agent的实验区域，需先看完整范围/限制再显式启动；未知响应核对原意图，分页读取结果不重跑计算。CLI仍用operator文件；API已解析实际发布版本并保存来源。各项独立验收和未完成范围见[完成矩阵](../stock_research_completion.md)。
