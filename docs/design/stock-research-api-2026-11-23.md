# 研究API与运行管理实施约束

沿plan.md阶段四开发，使用现有Agent界面扩展，不新增页面路由。首先接通研究运行和固定报告的独立HTTP查询与生命周期；参数、主题、自选、持续名单、聊天工具及前端按其持久化契约继续接入，不把只有接口声明的功能当作交付。

- [x] 所有业务端点受固定workspace的Bearer认证约束；缺token拒启，令牌不进入URL/公开响应/前端持久化。仅监听loopback，浏览器Origin须同源或显式部署白名单。
- [x] 显式Pydantic响应与code/message/data/correlation_id；UUID验证、分页SQL、稳定排序、来源不可用/状态冲突等错误不泄露驱动信息或凭据。
- [x] 创建运行先冻结并保存输入后返回202；任务留引用、可查询/取消/有界关闭，重启依赖数据库状态及幂等恢复，初选成功后不可覆盖。
- [x] SSE事件以报告修订为稳定游标，可断线续读；查询固定报告版本，不将本地原文文件路径暴露为任意读取接口。
- [x] 临时PostgreSQL+实际ASGI生命周期验证401/403/404/409/422/503、跨workspace、读写闭环、取消和重启，无外部网络。
- [ ] CLI serve与只读客户端接线；本机真实HTTP认证查询预览报告；受影响文档、工具清单、环境模板同步。

范围依赖：行情/基准更新与services唯一调度所有者在阶段五落实；自然交易日及时完成、正式通知、Tailscale入口与费用后绩效均需各自独立证据。

验证：全量Python5949通过；随后155项研究测试通过，覆盖新增来源不可用与非交易日。真实HTTP受理202并查询五只初选，互评仍失败并保留回执。CLI serve已接线；独立只读客户端、Agent界面及后续查询能力待接。无wiki checkout/远端CI/部署验收。
