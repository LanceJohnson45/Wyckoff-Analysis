# Agent历史评估区域

PDP豁免：单页修补。本迭代补齐 `plan.md` §13现有Agent的实验区域，沿用单用户operator及私有评估API，不新增路由、角色或参数发布流程。后端已实现不等于界面已经完成，以下为本轮实现/验收依据。

用户展开区域后读取当前发布参数和已有评估；只有显式提交才发起量化。表单选择美国交易日，显示当前Martin参数版本；当前池回溯单独勾选并告知非严格时点资料限制。显示“量化池回放”，不称模型初选或交易回测。

| 状态 | 用户所见与动作 |
|---|---|
| 折叠 | 不读取评估资源、不自动启动计算 |
| 初次加载/失败/空 | 有读取提示/明确失败重试/暂无记录，失败不当空结果 |
| 可提交 | 日期必填，实际参数读取成功；提示独立于当前历史报告的冻结参数 |
| 提交中 | 本次按钮和字段锁住，防重复点击 |
| 提交结果未知 | 保存原body/key，字段继续锁住；显式“核对原提交”重放原意图，不新建key |
| pending/running | 显示状态和20截面进度，定时读取原任务；可请求取消 |
| cancel_requested | 告知等待实际计算退出，不提前显示已取消 |
| failed/cancelled | 可在剩余次数内续跑原任务，原期限由后端检查；不重置配置或行情 |
| completed | 固定结果与窗口分开读取；结果不因重新读取而重算 |

历史任务用截止日、参数版本、创建时间和状态标识，不将UUID作为展示标题。任务历史和逐股结果均用服务端页码/总数，上一页/下一页边界禁用。选择任务后动作固定该ID；切换历史报告不重新解释这个任务。

结果先显示20个截面、两策略、净化后可用样本及来源限制。默认20日窗口，可选1/3/5/10日；可按策略筛选。逐股显示扣成本变化、相对SPY、MFE/MAE、原分区与净化标记。pending、缺数和封存分别显示，不伪造为0；封存不提供释放按钮。列出服务端限制及人工审查待完成状态，不产生参数建议或自动发布。

验收至少覆盖：展开不启动计算；显式提交至完成；字段校验与数据不足失败；未知响应原提交核对；取消等候真实退出及原任务续跑；固定结果/缺数/封存；任务及样本分页；外部文字转义；旧连接不支持资源时明确提示。契约和渲染检查使用现有Vitest；真实操作另外在隔离PG/API/Vite完成，不将静态渲染当作整条用户流程已验。
