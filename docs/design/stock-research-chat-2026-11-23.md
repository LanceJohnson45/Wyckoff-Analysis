# 固定报告研究对话

在既有/chat的策略研究子视图内提供独立研究问答，不新增页面。报告/个股讨论绑定当前report_id，使用研究后台持有的可信模型连接和隔离DSH；不把冻结JSON转交通用交易聊天工具集。八项规范工具为market_overview、group_strength、stock_factors、stock_history、compare_stocks、strategy_rules、report_read、run_status；知识工具待已有授权接入后另验。

工具端固定workspace/报告/运行，只读HTTP身份仅交给受控工具进程，不持有PG或operator权限。模型不能指定报告、URL、SQL或文件路径。Harness实际目录必须等于八项名单，SDK事件和guard均检查工具名称、20次预算和deadline。工具成功返回的真实标量/日线引用写入私有注册表；结构化回答的观点引用和数值claims逐值验证，修正一次仍错则保存失败。

新增受维护chat_turns表：每问一个UUID、报告、会话根、父问答、顺序及幂等摘要。父问答作为续接CAS锚点，一个父问答仅有一个后继；父未结束或报告不一致时拒绝。失败问题仍留存，后续只纳入有界的已保存历史，不由浏览器拼造。输入与原始回执只在私有存储，公开白名单不含令牌、路径或模型连接地址。共享行情只读身份不能读取私人问答，问答HTTP仅operator可访问；正式多用户身份托管仍属于部署验收。

POST /v1/chat-turns返回202，后台执行有界；GET按报告/会话SQL分页及单问答查询，显式取消等待子进程回收。重启不自动重复未知模型请求，失联且无活锁的pending/running回执明确为执行中断；旧回答不覆盖。原报告、初选、名单和参数不受对话影响。
