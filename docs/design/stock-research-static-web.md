# 同进程研究工作台入口

`plan.md` §4要求React静态资源与研究API由同一进程、同一来源提供。沿用已确认的本机单用户范围及现有Agent，不新增业务页面或Node常驻服务。公开站点的生产构建和账号流程保持；本机构建只复用现有研究路由及组件，不加载Supabase登录、遥控页或站点分析代码。

operator显式配置绝对路径 `STOCK_RESEARCH_WEB_DIST_PATH` 才启用静态入口。未配置仍是原Bearer API；错误/缺失/非专用产物启动失败。专用HTML仅在 `/chat` 提供，根入口重定向到此；仅打包资产可读，不兜底任意路径、暴露源码或跟随产物外符号链接。资源身份和Content-Type可核对，HTML及私有响应禁止缓存。

浏览器入口核对loopback Host及实际端口、同源Origin和Fetch-Site。HTML签发12小时HttpOnly、SameSite=Strict、host-only会话cookie，按端口分名；签名密钥仅在API进程内，重启轮换。浏览器使用既有 `/api/stock-research` 前缀；同进程桥接验证会话、来源、方法/路径及正文上限后，才以内存中的operator身份调用原ASGI链。直接 `/v1` 仍须Bearer，不接受浏览器cookie替代；不提供任意URL、路径或额外盘前写能力。开发代理和Python入口共用打包的声明式路由清单。

仅桥接在认证前拒绝的401带会话刷新标记。前端可合并为一次同源HTML重读以更新cookie，再重放原请求一次；原正文、幂等键、取消信号和总超时保持。网络未知/5xx/一般401均不据此自动重发。HTML刷新不卸载React，未知提交意图保持；会话、API密钥均不进入localStorage。

静态入口设置CSP（脚本/连接仅同源、禁框架嵌入和对象）、nosniff及no-referrer；只允许HTTP loopback。Tailscale身份代理的实际外部同源/转发契约另验，不把本机成功写成远程访问已完成。原launchd继续托管同一API进程；新包只有当前提交全部CI成功、显式新表初始化且研究/问答/准备/评估均无活动、所属worker退出后才能采用。
