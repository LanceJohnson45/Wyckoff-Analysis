# 历史量化评估CLI与私有作业API

`evaluate` 现已接入包入口，用于20个历史截面的基线量化池回放。它调用正式 Martin 和生产 Wyckoff 适配器，不调用模型、修改生产参数、创建订单或发送通知。工程边界见[设计](design/stock-research-evaluations.md)。

```bash
.venv/bin/python -m stock_research.cli evaluate --profile baseline-v1 --cutoff 2026-11-20
.venv/bin/python -m stock_research.cli evaluate-parameters --profile baseline-v1 --cutoff 2026-11-20 --field support_atr --values 0.5 0.75 1.0
.venv/bin/python -m stock_research.cli evaluate-combined-parameters --profile baseline-v1 --cutoff 2026-11-20 --values 1.0 4.0 0.8
```

CLI输入为 operator 配置的本地行情库、成分/分类文件和两策略参数文件；API作业在准备阶段通过既有发布解析器冻结实际参数、截止日有效的主题/自选和来源。仅接受已完成正式收盘的截止日，profile必须与实际Martin参数版本一致。一次只读一致备份取得截止日前最多400个交易日、最多250000行；超限报错，不静默截断。不联网补数，不使用配置的供应商基准补充文件。三基准在本地源中须有足够长的完整历史：每个候选日有320根历史，且预留20日标签；20个候选至少需要359个连续交易日。数据不够或抽中截面质量未通过时明确失败，不能以空结果或重复日期凑数。

`review-evaluation --report <report.json>` 只读同目录的正式分析产物，为 Martin 与 Wyckoff 各生成10条入选观察和10条排除记录；封存截面可用于补足入选审查，但不读取其表现。任一策略不足10条时命令失败，不能以重复记录或人工补造凑数。该清单只供逐条人工审查，不生成收益结论或参数调整建议。

只有接受当前清单回溯限制时才显式增加 `--allow-current-universe`。该模式按截止日当前成员/分类生成单独派生版本，原版本全文保留；调整有效期不是取得了历史成分证据。源文件和已冻结报告不修改。无该标志则尊重原有效期，不静默回填历史成员。

抽样按候选日过去SPY20日收益排序，含两端等距抽取20个秩，然后按日期分为12/4/4。20日标签跨下一组起点时标记 `purged=true`。`usable_sections` 按截面计数，不把两策略算成40个独立日期；少量或净化后不足样本只作描述。封存组记录量化证据但不输出后续表现，本轮没有释放开关。

结果写入 `.stock-research/evaluations/<请求摘要>/`：

- `request.json` 冻结输入、源码、参数、覆盖门槛、回溯选择和美股成本估算。
- `input.json` 保存一次原始版本、带出处日线和隔离原因全文。
- 每日 `*-snapshot.json` 固定原快照身份/摘要；两份策略JSON保存正式量化池、事实及排除。
- `report.json` 保存20日截面/两策略的分母、原排除计数、池归属、观察窗口和限制。

同输入重跑校验并复用已完成证据，不覆盖；中断后的完整单策略产物可复用。损坏证据、不同绑定或不一致输出拒收。源码、输入、参数、覆盖或成本变化会另起请求目录。CLI内逐截面检查总预算，单个同步计算过程中仍依赖CLI进程终止；API另有隔离进程硬期限，不混称同一种超时。

`evaluate-parameters` 只支持首轮计划的 `support_atr`、`extension_atr`、`contraction_ratio` 三个字段，每次必须显式给三个不重复值。该命令复用当前发布输入但生成带 `:experiment:` 后缀的独立参数版本，三个结果分别落请求摘要目录；不发布生产参数，组合实验必须等三个单组实验完成并另行显式运行。

`evaluate-combined-parameters` 仅接受三个计划字段的显式值，并要求三者都不是当前生产默认值；组合仍生成带 `:experiment:combined:` 的独立参数版本，不复用单组结果推断，也不发布生产参数。组合冻结输入保存在 `parameter-experiments/combined/input.json`，与三个单组文件内容一致时允许复用；内容不同则拒绝。同一组合重跑复用原报告。

表现按截面收盘参考价观察后1/3/5/10/20个XNYS交易日，百分数以百分点计。净收益扣 `core.trade_friction.round_trip_cost_pct(code="<symbol>.US")` 的既有工程估算；净超额减去SPY毛收益，不等于实盘alpha。MFE/MAE从参考收盘起算，含零，使用后续窗口高低价；当前日高低价不混入。窗口未走完保留pending；内部缺股票或SPY行情保留missing_data及具体日期，不将缺数行直接丢掉。

## 私有评估作业

以下为源码和隔离验收能力；正式本机运行包采用必须另有当前提交成功CI及部署记录，不能据此认为已安装的旧API支持这些路由。

| 方法与资源 | 行为 |
|---|---|
| POST /v1/evaluations | Idempotency-Key（16～128字符）与profile/cutoff/allow_current_universe，持久受理后202 |
| GET /v1/evaluations、GET /v1/evaluations/{id} | 小作业账本分页及状态，page_size最多100，不读取行情文件 |
| POST /v1/evaluations/{id}/cancel | 先记取消意图，实际回收进程后才提交cancelled；其他实例拥有时可先返回cancel_requested |
| POST /v1/evaluations/{id}/retry | 显式续跑原身份、输入和剩余期限；终态成功、源码已变、预算/次数耗尽均409 |
| GET /v1/evaluation-results/{id} | 固定结果元数据及40份截面/策略摘要，不夹带全部观察窗口 |
| GET /v1/evaluation-results/{id}/samples | 逐股窗口SQL分页，支持strategy过滤，缺数和封存成员不丢弃 |

这些资源均为operator私有；外部只读身份和盘前身份不能借此读取个人实验或启动计算。请求不接受路径、SQL、连接或模型字段，本机同源代理仅放行上表对应路由和方法。成功/错误继续使用研究API四键契约。

`evaluation_jobs` 保存原请求摘要、冻结配置和状态，`evaluation_results` 只追加成功元数据，`evaluation_samples` 保存逐股窗口；结果、样本和成功状态同事务提交。需要显式 `init-schema` 新增三表；服务启动不自动迁移。新作业与原请求重放分开处理，同一key不能换载荷，重放也不依赖原operator文件仍存在。

同workspace最多一批API评估实际执行，且与研究/问答共用实例接单容量2。worker不实例化Settings，不继承模型/数据库/Personal身份；从临时工作目录运行，只接绝对受控定位和冻结参数。输入协议128KiB、stdout总计64KiB、版本文件4MiB、冻结输入512MiB、结果32MiB，并在SQL侧限制源行数。上述是输入/协议边界，不是进程RSS硬上限。

原总期限使用既有运行预算（默认3000秒），worker最多2次总尝试，异常进程退出可自动补算一次，显式续跑与重启恢复不重置计数或期限。取消/超时/父端EOF须等候所属进程组退出。服务关闭将已停止的原任务保留为pending供恢复；取消收尾在原执行锁内提交，另一拥有者不能抢先恢复并被旧状态覆盖。准备失败持久化failed，不留下无限pending。

资料前提失败在worker协议中单独保留：`evaluation_history_insufficient`表示完整历史截面不足20个，`evaluation_quality_failed`表示抽中截面的行情质量未通过。这两类均为failed且不自动重试；续跑同一冻结输入不能补齐资料，API拒绝原任务retry（409），页面说明需核查/补齐数据后创建新评估。进程中断和取消仍按原预算恢复；不根据自由文本异常猜测失败类型，不改变质量或历史门槛。

API将原始行情一次物化到作业目录；结果目录的input.json为同文件硬链接，避免再复制完整行情。冻结后即使源行情修订，续跑也只读原文件及摘要；旧成功策略产物、原报告和原参数发布不改变。逐股结果只描述量化池。

## Agent中的量化池回放

现有Agent页底部接入“历史评估 · 量化池回放”，不增加路由。初始折叠不读取评估；展开只读当前发布参数及历史任务，只有点击“创建历史评估”才启动计算。截止日必填，使用实际当前Martin版本，当前成分回溯需单独勾选限制声明。历史报告切换不会替换已固定的评估请求。

提交结果未知时保留原请求正文与幂等键，字段锁定，显式“核对原提交”重放相同请求，不自动重试POST。取消/续跑结果未知时，只读原任务核对后才开放后续操作。折叠区域保留尚未核对的请求，但停止评估轮询；未确认时请保持页面，整页刷新不持久保存浏览器内的原提交意图。

任务显示截止日、参数版本、创建时间、20截面进度和尝试次数；取消意图不冒充实际终态。历史每页5次，逐股每页20条，使用服务端分页和策略过滤。完成后固定元数据与逐股窗口分别读取，切换1/3/5/10/20日窗口不重算；pending、missing_data、sealed明确区别，封存不公开表现。跨区标签保留可查并标记剔除，人工审查继续显示待完成。旧API不支持评估时明确提示，不把失败当空记录。

该区域已在临时原生PG、真实API/worker/Vite及三股360日合成资料下完成页面验收：显式创建到20截面完成，任务两页/样本三页，策略/窗口/成本及封存显示，必填/周末拒收，实际旧版API资源缺失提示。API受理后截断回执使表单进入未知态，折叠再展开保留原请求；显式核对前后任务/结果/样本不增。取消回执截断后页面锁住续跑，读回原任务才解锁；实际worker退出后，同任务第二次尝试完成，修订源行情仍不改变冻结配置/输入/期限。API与页面重启后原任务可读，前六条任务载荷未变。资料不足及质量失败各用真实worker回归和页面复验，说明原因且不再提供无效续跑。
