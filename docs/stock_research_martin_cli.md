# Martin量化观察CLI

`codex/stock-research` 已接通共享日线因子、成熟趋势回调和早期转强回调。输入必须是质量通过且摘要有效的固定快照；本阶段只生成最多30只的模型复核池，`model_selection` 始终为null。[Wyckoff生产适配](stock_research_wyckoff_cli.md)已接通独立量化入口，[独立模型初选与互评预览](stock_research_executor.md)已接通，[研究API](stock_research_api.md)已接本机预览，自动任务仍待实现。

## 运行

在仓库根目录使用Python 3.12环境，行情、分类、独立基准及研究库配置见[数据CLI](stock_research_data_cli.md)。将 `STOCK_RESEARCH_PARAMETERS_PATH` 指向 `config/research/baseline-v1.json`，或另存一份经审阅的参数文件。

```bash
# 使用当前配置创建并持久化快照，再分析；不自动同步云端行情
.venv/bin/stock-research analyze --market us --as-of 2026-11-20 --strategy martin --no-llm

# 重放已有固定快照；SNAPSHOT_FILE为snapshot命令返回的path
.venv/bin/stock-research analyze --market us --as-of 2026-11-20 --strategy martin --no-llm --snapshot-file "$SNAPSHOT_FILE"

# 两个独立进程比较同一快照的ATR/ADR；不是完整策略回测
.venv/bin/stock-research benchmark --as-of 2026-11-20 --profile baseline-v1 --snapshot-file "$SNAPSHOT_FILE"
```

`--no-llm` 必须显式提供；本页描述 `--strategy martin`，Wyckoff使用独立参数文件与算法入口。截止日与快照不一致、质量失败或参数无效时终止。输入文件方式不需要新建数据库连接。读取行情和数据质量排除仍沿用数据阶段契约。

结果摘要返回完整报告 `path`、快照/参数/报告摘要、观测数量与候选池。完整报告包含每只股票的原始因子、两分支条件真值、排除原因、全部候选支撑、采用支撑、结构状态、已确认锚点、评分分项和行业事实。两分支同时命中保留双标签，池内symbol去重；不足30只不补足。

## 公式、条件与排名

因子与阈值依据分开记录，资料核对见[因子出处](martin_luk_factor_provenance_2026-11-23.md)。`MartinParameters` 拒绝未知键、错规则名、倒置EMA和无有效评分权重。每个规则保存enabled、action、概念/公式/参数出处；作用方式支持exclude、warn或bonus。禁用条件仍计算真值并保存在报告，bonus不构成硬排除，评分权重独立配置。

| 项目 | baseline-v1行为 |
|---|---|
| EMA | close的ewm，adjust=False，9/21/50；斜率比较5根前 |
| ATR、ADR | 14根真实波幅简单平均；20根平均(high/low−1)×100 |
| 相对强弱 | 同日期20根个股收益减SPY收益，单位百分点 |
| 收缩 | 近3根均幅/此前10根均幅≤0.7，且对应量比≤1；默认作为辅助项 |
| 成熟分支 | EMA多头且均上升、收盘不低于中线；近5根回调；低点接近收盘下方EMA快/中线，带宽0.75ATR；延伸≤3ATR |
| 早期分支 | 观察近20根中的最近一次已发生突破，平台为事件前60根最高价；不要求成熟EMA排列。突破后任一收盘低于平台减0.75ATR即结构失效 |
| 早期回测 | 当前回调至有效平台或上升EMA带；所选支撑的连续触带算一次，离带再进入算重复，默认只保留首次。当前日不作为新的突破锚点 |
| 支撑选择 | 保留全部候选；从收盘下方有效支撑选最近者，同距离按平台、中线、快线排序 |
| AVWAP观察 | 左右各3根确认的摆动点及已发生突破为锚；日线典型价格估算，标明确认日期，硬过滤关闭 |
| 行业/主题 | 完整活动组为分母，至少3只有效成员且覆盖≥80%才评分；RS中位数、1/3日上涨比例与趋势健康度分别截面排序后合成 |
| 个股评分 | RS25%、最强可用组20%、支撑接近度20%、条件完整度15%、量比10%、幅度收缩10%；缺辅助项对可用权重重归一化，无可用权重排除 |
| 合并 | 两分支分别按得分降序、symbol稳定排序，早期/成熟按名次轮流取，确定性去重 |

所有窗口、带宽、权重及早期结构识别属于工程研究定义，没有参数优化或历史收益有效性的结论。金额代理未确认复权价格与成交量单位兼容，保存为缺失；当前扫描不应用真实成交金额门槛。日线高低参考也不等于分钟触发、可成交价格或买入指令。

## 产物与验证边界

报告以快照摘要、完整参数及schema版本构造缓存键，保存在忽略的 `.stock-research/analyses/`；读取时重新验证摘要，已有不同内容拒绝覆盖。相同输入复用已发布报告，修改参数产生新文件。当前量化报告为本地不可变产物，尚未接入因子/候选的PostgreSQL表及运行状态机；数据快照仍由数据阶段持久化。

参考公式黄金样本来自来源分支 `dc5fec0e` 的实际 `core/martin_luk.py` 输出，夹具保存文件SHA及多个日期的EMA、ATR、ADR、收益和ATR距离。测试同时验证前缀计算不受未来追加行情影响、右侧确认、首/重复回测、禁用规则、缺数据和报告损坏拒绝。

AKQuant 0.3.93对拍仅覆盖其可表达的ATR/ADR，检查证券/日期顺序、预热缺失和有限数值，绝对容忍1e-10；EMA尚无已对齐的对应算子，生产仍用pandas参考路径。对拍产物位于 `.stock-research/benchmarks/`，包含独立进程冷/热计算耗时和峰值内存。峰值含输入解析、两次计算及运行时，冷/热计时不含父进程准备；单次测量不能证明完整策略更快。

当前公开股票池、分类及复权数据存在[数据来源限制](stock_research_public_data.md)，完整继承到量化报告。无历史实验、模型复核、费用后绩效或交易许可结论。
