当前版本可用于**日线形态学习、历史复盘、自选股候选整理**，可以辅助投资研究，但不能据此判断买入时机、仓位、可成交止损或预期收益。计算符合已公开的“日线研究v1”定义；它只实现Martin方法的一部分，不是完整复现本人交易决策。

## 计算与理论的逐项区别

| 项目 | 实现核验 | 与理论关系及缺口 |
|---|---|---|
| EMA9/21/50 | 以首根收盘初始化，逐根递推alpha=2/(N+1)，与独立循环算术一致 | 符合观察均线方向的工具用途；要求三线排列且5根上升是程序自定门槛，可能漏掉刚转强的首次回测 |
| ATR14 | max(H-L,abs(H-昨收),abs(L-昨收))后取14根简单均值，独立核对含跳空数据 | 数学正确；使用SMA口径而非Wilder平滑。0.75ATR/3ATR均非已证实的Martin固定参数 |
| ADR20% | 20根均值((H/L)-1)*100，独立核对 | 不与ATR混用；20根为研究口径，原视频未披露统一窗口；ADR>5%不设为全部股票硬门槛 |
| 回调候选 | 均线趋势、真实回落、日低靠近9或21EMA且收在相应线上、未延伸 | 能找靠近支撑的日线样本；没有识别趋势早晚、首次/反复回测、平台收复、较高低点或上方阻力。强势标签主要是均线结构，不能自动推断板块领先 |
| 收紧/突破 | 近3根量幅相对前10根；突破用之前已知10根最高价，未包含当天高点 | 窗口和70%是研究假设；不能等同所有平台、内包日/周、旗形或开盘区间突破。突破标签不代表已按该价成交 |
| U&R | 当日低跌破此前20根最低，收盘站回；弱趋势另警示 | 对应日线收复的一个严格子集。原方法不规定必须20根低点或同日收盘收复，当前会漏掉其他支撑、多日收复；也不能判断旧低有无足够结构意义 |
| 相对强度 | 21个相同个股交易日期的20段收益，减基准对应收益，单位百分点；不补齐缺失日期 | 是证据列，不是筛选硬门槛；不同股票数据截至日不同，不能直接将全部当成同日排名 |
| 参考位 | 回调本日高/5根低；收紧10根高/3根低；U&R本日高/本日低；多标签按文档优先级处理 | 都是事后已知日线位置，供下一阶段观察。不是教材分钟前K高触发，不是实际入场/止损指令，也没有仓位与退出管理 |
| 截止日 | 超过截止日的行不参加指标；未来数据不改变已有日期结果 | 避免日线计算前视；日线仍不能确定一根K内先触发还是先止损。点“扫描”是收盘后研究，不是盘中实时信号 |

## 本次发现与修改

相对强度为负时，原解释写“较基准高 -X”，数值正确但语言容易误导学习者。现改为正数“领先”、负数“落后”、零“持平”，负数增加“均线趋势或形态标签不代表跑赢基准”提示。

没有为迎合教材而擅自改变原筛选阈值。没有发现所测EMA/ATR/ADR/收益公式错误；这并不证明所有形态判断具有预测能力，也不等于完成了理论全部量化。

新增5项测试：3个截断位置的独立算术核对（包括跳空与未来数据截断），以及正/负相对收益解释。加上既有核心形态、无前视、真实SQLite、组件、交易时钟等测试，最终**67 passed（5.39秒）**：

```sh
LUK_REAL_DATA_TESTS=1 /tmp/luk-verify-312/bin/python3.12 -m pytest \
  tests/test_local_market_store.py tests/test_martin_luk.py \
  tests/app/test_martin_luk_view.py tests/test_trading_clock.py \
  tests/test_indicator_rule_engine.py -q
```

先复现了正/负相对收益措辞测试失败，再修改并回归。独立算术不用pandas的ewm/rolling结果充当预期答案。真实CSV和本地同源对照验证输入路径一致性，不是第二行情源真实性对账。

实际行情也另做了独立逐根算术核对（002893、301226、002885），包括三个EMA、ATR、ADR、收益、距离及同日基准收益；均在1e-11容差内一致。默认参数下301226同时命中回调和收紧，参考高39.040、失效参考36.000，核对确实采用文档中的收紧优先级。明细在logs/martin_luk_independent_real_calculation.json。

有教学意义的例子：002893近20日自身收益约-0.83%，相对沪深300却领先7.48个百分点。这不是算错，而是对应日期基准下跌更多。不能将相对领先等同绝对上涨，更不能由此推断市场环境适合进攻。002885则是U&R与弱趋势、相对落后同时出现，不能把U&R标签等同“已反转可以买”。这些代码仅为验证样本。

## 怎样作为学习/投资辅助工具使用

1. 先检查个股实际日期；旧日期只能用于对应历史复盘。当前不宜把全库结果直接当当天候选排名。
2. 隐藏后续走势，在某历史截止日扫描，读出均线、量价、标签和失效参考；用规则说明解释为什么入选/未入选。
3. 另看周线与小时位置、板块强弱、是否首次回测、上方阻力、AVWAP及事件。当前网页没有完成这些检查。
4. 把观察与执行分开：需要分钟触发时另取分钟数据；预先写出取消条件、实际可成交价格、风险预算和退出方案，先做模拟记录。
5. 用样本外、含成本与滑点的回测或前向模拟评估规则。当前没有胜率、期望收益、最大回撤或交易优势证据；当前成份股回溯还存在幸存者偏差。

普通A股的交收/回转限制使美股当日分钟紧止损不能原样照搬；参考失效价不能保证能够卖出或封顶损失。参见[上交所2026年交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)。

SEC/FINRA对自动投资工具也强调理解方法、假设及局限，警惕收益承诺，参见[Automated Investment Tools](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-alerts/investor-56)。这里的工具适用判断来自本次实现与证据范围，不是监管机构对本项目的认证。

优先改进方向：先完成逐股数据新鲜度验收，再加入可保存的人工理论检查与复盘记录，最后评估明确执行规则的回测。当前不要把“命中标签”直接翻译成“可以买”。
